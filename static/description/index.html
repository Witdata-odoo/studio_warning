Studio Warning

Este módulo añade una capa de control y advertencia antes de acceder a la herramienta Odoo Studio. Su propósito es asegurar que los usuarios estén al tanto de los riesgos que implica modificar el sistema y notificar automáticamente al equipo de soporte o a los responsables (Partners) cuando un usuario decide utilizarla.

¿Qué hace este módulo?

  • Aviso de Responsabilidad: Cuando un usuario hace clic en el icono de Odoo Studio, se bloquea el acceso directo y se muestra una ventana emergente de confirmación.
  • Aceptación de Riesgos: El usuario debe leer un mensaje de advertencia donde se le informa que asume la responsabilidad de los cambios y que no se brindará soporte por errores derivados de su uso.
  • Notificación por Correo: Si el usuario acepta los términos y decide continuar, el módulo envía automáticamente un correo electrónico de alerta a una dirección preconfigurada, registrando el nombre de usuario y dejando constancia de la acción.

Configuración

Para que el módulo envíe los correos de alerta correctamente, es indispensable configurar la dirección de destino siguiendo estos pasos:

  1. Inicia sesión en Odoo con un usuario que tenga permisos de Administrador.
  2. Activa el Modo Desarrollador (puedes hacerlo desde los Ajustes generales de Odoo).
  3. Dirígete al menú Ajustes > Técnico > Parámetros del sistema (ubicado en la sección de Parámetros).
  4. Utiliza la barra de búsqueda para encontrar la clave: partner.studio.email
  5. Edita el registro y en el campo Valor, ingresa la dirección de correo electrónico a la que deseas que lleguen las alertas (por ejemplo: soporte@miempresa.com).
  6. Guarda los cambios.
Nota: Si el parámetro no se encuentra en la lista, puedes crearlo manualmente pulsando el botón "Nuevo", colocando partner.studio.email como clave y tu correo como valor.
